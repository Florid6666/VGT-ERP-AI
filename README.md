# VGT ERP AI — Autonomous Cloud Enterprise ERP Suite

An enterprise-grade web application built with **React**, **TypeScript**, **Tailwind CSS v4**, and **Vite**. Features an Apple-inspired design language, interactive MacBook telemetry showcases, real-time metric sparklines, multi-currency sub-ledger demos, and executive CRM forecasting.

---

## 🚀 Features

- **Apple Light & Dark Gallery Aesthetics**: SF Pro typography scale,Action Blue (`#0066CC`) interactive signals, light parchment (`#F5F5F7`), and museum dark tile (`#1D1D1F`) sections.
- **Interactive MacBook Pro Device Frame**: Realistic laptop mockup display with live interactive screen tab controls (*Plant Telemetry*, *Predictive CRM*, *Autonomous Freight*, *Multi-Subledgers*) and floating HUD stat badges.
- **Live Telemetry & Metric Sparklines**: Dynamic metric cards recalculating live telemetry on click.
- **Enterprise Command Center**: Multi-node dashboard mockup with auto-optimizing yield charts and plant sensor stream alerts.
- **Microsoft Co-Sell Alliance Callout**: Deep Azure AI & Dynamics 365 integration showcase with enterprise compliance certifications (ISO-27001 & SOC2 Type II).
- **Responsive Navigation & Lead Generation**: Mobile overlay drawer, smooth scrolling, and custom toast notification system.

## 🚦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Jivansatapathy/ERP-Website.git
   cd ERP-Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
